# Typoprint handbook

**Markdown in. Beautiful PDFs out.**

Write in Markdown. Print like a publisher.

Typoprint turns plain Markdown into polished, reproducible PDFs. It runs fully
offline from a Python library or a one-line CLI, with book-style and compact
report layouts you can restyle or replace.

## Just want a PDF?

[Install](install.md) it, then run `typoprint notes.md`. The
[command line guide](cli.md) covers folders, ordering, covers, and presets.

## Building it into an app or worker?

The [Python API](python.md) renders from strings, files, or in-memory chapters,
with no side effects.

## Want your own look?

[Templates and content rules](extensions.md) show how to add layouts, transforms,
and validators.

## Contributing or shipping a release?

See [Verification](verification.md) and [Releasing](releasing.md).
