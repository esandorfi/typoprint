# Code of conduct

Typoprint is a welcoming, harassment-free project for everyone. Be kind, assume good
faith, give constructive feedback, and keep discussion about the work.

Unacceptable behavior includes harassment, insults, discriminatory language,
personal attacks, and publishing others' private information.

## Reporting

Use GitHub's own tools: report an issue, comment, or pull request from its **⋯ menu →
Report content**, or block and report a user from their profile. Maintainers may
edit, hide, or remove contributions and restrict participants who break these rules.

For security problems, see [SECURITY.md](SECURITY.md) instead.
